# Doctor App (eChanneling Revamp)

A simple, lightweight Flutter app for doctors to manage appointments, patients, and availability. This repository contains the mobile application code (mostly Dart) for the eChanneling Revamp project.

## Features
- Appointment Management
- Session Management
- Teleconsultations
- ePrescription
- Patient Health Record Access
- Income View
- Notifications & Reminders
- Profile Management

## Tech stack
- Primary: Dart / Flutter
- Other: C++, CMake, Swift (platform bits), native code as needed

## Requirements
- Flutter SDK (stable)
- Android Studio / Xcode (for platform-specific builds)
- A connected device or simulator/emulator

## Quick start
1. Clone the repo:
   git clone https://github.com/eChanneling-Revamp/Doctor-App.git
2. Navigate into the project:
   cd Doctor-App
3. Fetch dependencies:
   flutter pub get
4. Run on a device or emulator:
   flutter run

## Build
- Android APK:
  flutter build apk --release
- iOS:
  flutter build ios --release
